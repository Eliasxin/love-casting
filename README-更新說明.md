## GitHub 更新方式

1. 將 `index.html` 與 `styles.css` 放到 `Eliasxin/love-casting` 專案根目錄，覆蓋同名檔案。
2. 原本 `app.js`、`data/chapters.json`、GitHub Actions 工作流程、海浪影片與圖示都不需要修改。
3. Commit 並等網站部署後，在手機與桌面確認「節目介紹」區塊。

> 注意：本次是依你前一版《節目主創與八位男孩介紹》更新包製作，若 GitHub 上的 index.html/styles.css 其後另有更新，請先比對再覆蓋，以免遺失新功能。
